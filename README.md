# Johnly & Kaycee — Moving Background Wedding Invitation

This version keeps the existing GitHub Pages wedding invitation and adds a lightweight, CSS-only animated background designed to match the ivory, champagne, blush, taupe and sage-inspired luxury theme.

## Upload to GitHub Pages
1. Replace the existing `index.html`, `style.css`, and `script.js` with the files in this folder.
2. Keep your existing `images/` and `music/` folders and files.
3. Commit/push the files to the repository.

No build process or npm installation is required.

## What was added
- Slow drifting champagne/ivory glow
- Floating decorative botanical-style symbols
- Gentle depth movement behind sections
- Transparent light section surfaces so the animation remains visible
- Reduced-motion support for accessibility
- No external animation library

Your existing RSVP endpoint, photos, music and wedding content remain unchanged.
